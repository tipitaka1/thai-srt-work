# thai-srt-work · 숲속 수행승 법문 듣기

휘스퍼로 뽑은 태국어 법문 자막에 한글 독음과 한국어 번역을 달아, 폰에서 법문을 들으며 읽는 저장소입니다. 한국어 더빙으로도 들을 수 있습니다.

**폰에서 열기:** <https://tipitaka1.github.io/thai-srt-work/>
홈 화면에 추가하면 앱처럼 열립니다 (안드로이드 크롬: 메뉴 → 홈 화면에 추가 / 아이폰 사파리: 공유 → 홈 화면에 추가).

지금 들어 있는 법문은 아잔 마하부와의 「모든 괴로움 덩어리는 감각 욕망 번뇌에 모여 있다」입니다(2003년 10월 11일 저녁, 당시 90세, 왓빠반땃 스님들에게).
- 본 법문 21분 전체가 들어 있습니다. 원본 녹음 3:35, "내가 이렇게 아파서…"부터가 0:00입니다.
- 앞의 금·달러 모금 이야기(1~35줄)와 끝의 잡음·휘스퍼 반복(340~348줄)은 뺐습니다.
- 168문장, 목차 6개입니다.

## 화면

- 맨 위 **차례**에 덩어리 여섯 개의 한 줄 제목과 시작 시각이 있습니다. 누르면 그 자리부터 재생합니다. 오른쪽 위 목록 단추를 누르면 언제든 차례로 돌아옵니다.
- 태국어 단어 위 작은 글씨가 한글 독음이고, 그 아래 줄이 한국어 번역입니다. 지금 나오는 문장의 번역은 진녹색으로 바뀝니다.
- 번역이 폰 화면에서 1~2줄이 되도록, 휘스퍼 줄을 넘나들며 문장 단위로 다시 나눴습니다(`work/LT2401/talk_ko.txt`).
- 단어나 문장을 누르면 그 자리부터 재생합니다. 화면은 지금 문장이 아래쪽에 닿을 때만 한 번에 넘어갑니다.
- **보기** 창(세 줄)에서 다음을 고릅니다. 고른 값은 그 폰에 기억됩니다.
  - 글자 크기, 줄 간격(50~150%)
  - 태국어·독음·번역 보이기
  - 노래방 표시: 말하는 단어를 따라 색이 차오릅니다. 기본은 켜져 있습니다.
  - 화면: 자동(폰 설정을 따름)·밝게·어둡게(기본)
- 아래 막대의 말풍선 단추(「한」)가 **한국어 더빙** 켬/끔입니다. 기본은 켜져 있고, 누르면 같은 자리에서 태국어 원음과 더빙이 바뀝니다. 한국어 번역을 제미나이 TTS(목소리 Schedar)로 읽혀 문장마다 태국어 문장 자리에 놓았고, 태국어 원음은 작게 깔립니다.
- 오른쪽 위 공유 단추를 누르면 「제목 · 설법자 · 03-10-11」과 공유 전용 주소(`s/lt2401.html`)가 카톡 등으로 갑니다.
  - 이 주소에는 미리보기 태그가 있고, 누르면 앱으로 넘어갑니다.
  - 미리보기 카드는 `og/`의 정사각 그림입니다.
  - 예전 2분 샘플 주소(`s/lt2401-0920.html`)도 전체 법문으로 넘어갑니다.

초상: 「ประวัติ ท่านอาจารย์พระมหาบัว ญาณสมฺปนฺโน」 표지 (มูลนิธิพระสงบ มนสฺสนฺโต, www.sa-ngob.com)

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` | 웹앱 |
| `talks.json` | 앱에 뜨는 법문 목록 (음성, 자막, 더빙, 차례) |
| `media/` | 본 법문 음성 `LT2401_talk.mp3`(64kbps 모노), 자막 `.vtt`, 문장 시각·차례 `.json`, 한국어 더빙 `LT2401_talk_dub.mp3` |
| `s/` | 법문마다 카톡 공유용 주소 (미리보기 태그 + 앱으로 넘김) |
| `og/`, `img/` | 공유 카드, 초상 |
| `subtitles/` | 휘스퍼 348줄 전체의 노래방 VTT(1~339줄 독음·번역), 검토용 SRT(`태국어 / 독음 / 번역`, 검토 표시 포함) |
| `work/LT2401/` | 휘스퍼 원본 SRT, 단어별 시각 JSON, 독음·번역(`pron_ko.txt`, 검토 표시 포함), 태국어 토막(`seg_th.txt`), 문장 나누기와 차례(`talk_ko.txt`) |
| `tts/requests/` | 제미나이 TTS 요청 (이 폴더에 올리면 Actions가 읽힘) |
| `tools/` | 자막·음성 만들기 (`build_karaoke.py`), 앱 조립 (`app/core.html`, `assemble.py`), 공유 카드 (`render_card.py`), TTS (`tts_gemini.py`), 더빙 (`dub_align.py`, `dub_mix.py`) |

TTS로 만든 원음(테이크)은 `tts-work` 가지에 따로 모아 둡니다.

## 법문 추가하기

1. `media/`에 mp3와 vtt를 넣습니다.
2. `talks.json`에 항목을 하나 더 적습니다.
   - 꼭 있어야 하는 칸: `id`, `title`, `speaker`, `date`, `audience`, `audio`, `vtt`
   - 있으면 쓰는 칸: `chapters`, `dub`
   - 두 개 이상이면 맨 위에 고르는 칸이 생깁니다.

## VTT 형식

```
35
00:05:45.230 --> 00:05:49.940
<ruby>เอา<rt>아오</rt></ruby> <00:05:45.670><ruby>ฝาก<rt>팍</rt></ruby> <00:05:45.950><ruby>เป็น<rt>뻰</rt></ruby> …
<c.ko>죽든 살든 이 염송어에 다 맡기기로 했어요. 다른 길은 없다고요.</c>
```

- `<ruby>태국어<rt>독음</rt></ruby>`: 단어와 독음 한 쌍
- `<시:분:초.밀리초>`: 다음 단어가 시작하는 시각 (단어 바로 뒤에 붙은 시각은 그 단어가 끝나는 시각)
- `<c.ko>…</c>`: 한국어 번역 줄

단어 시각은 휘스퍼 단어 시각을 글자 위치로 나눠 잡은 뒤, 단어 앞뒤에 0.12초 넘게 붙은 무음을 음성 크기로 잘라 낸 값입니다. 화면용 VTT에서는 번역의 검토 표시(※, (?), 휘스퍼 메모)를 뺍니다.

## 다시 만들기

자막과 음성:

```
python3 tools/build_karaoke.py \
  --srt  work/LT2401/LT2401_2003-10-11.srt \
  --json work/LT2401/LT2401_2003-10-11_words.json \
  --mp3  <원본 mp3 경로> \
  --data work/LT2401 \
  --out  subtitles/LT2401_2003-10-11_karaoke.vtt \
  --site . \
  --reseg work/LT2401/talk_ko.txt --clip-name LT2401_talk
```

`--reseg` 파일은 한 줄에 한 문장입니다.
- 형식: `시작줄.토막-끝줄.토막|번역` (토막 번호는 `seg_th.txt`의 태국어 토막 순서, 0부터)
- `## 제목` 줄은 다음 문장에서 시작하는 차례 항목입니다.
- 첫 문장부터 끝 문장까지만 잘라 `media/`에 mp3·vtt·json을 씁니다.

한국어 더빙:

1. `tts/requests/*.json`을 올립니다.
   - 칸: `id`, `voices`, `style`(연출 메모), `ranges`, `lines`
   - 하나에 문장 수십 개를 넣어 한 번에 길게 읽힙니다. 조각마다 톤이 달라지지 않게 하려는 것이고, 한 번에 약 655초까지 됩니다.
2. Actions(`TTS takes`)가 저장소 비밀값 `GEMINI_API_KEY`로 제미나이 TTS를 부릅니다. 결과는 `tts-work` 가지에 `<id>/<목소리>.flac`으로 쌓입니다.
3. `tools/dub_mix.py`가 다음을 해서 더빙 mp3를 만듭니다.
   - 테이크의 문장 사이 쉼을 찾아 문장별로 자릅니다.
   - 태국어 문장이 시작하는 자리에 놓습니다. 다음 문장 전까지 안 들어가면 최대 1.25배까지 빠르게 합니다.
   - 태국어 원음을 작게 깔아 섞습니다.

```
python3 tools/dub_mix.py --side media/LT2401_talk.json --src <원본 mp3 경로> \
  --req tts/requests/LT2401_dub_A.json tts/requests/LT2401_dub_B.json tts/requests/LT2401_dub_C.json \
  --takes <tts-work 가지 폴더> --voice Schedar --out media/LT2401_talk_dub.mp3
```

앱 화면은 `tools/app/core.html`을 고친 뒤 `python3 tools/assemble.py tools/app/core.html .`로 `index.html`과 `s/` 공유 주소를 다시 만듭니다.

ffmpeg, numpy, soundfile이 필요합니다. 원본 25분 mp3는 저장소에 넣지 않았습니다. 키·토큰은 저장소에 넣지 않습니다.
