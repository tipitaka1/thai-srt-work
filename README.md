# thai-srt-work · 태국법문 따라읽기

휘스퍼로 뽑은 태국어 법문 자막에 한글 독음과 한국어 번역을 달고, 말하는 단어마다 색이 차오르는 노래방식 자막(WebVTT)으로 듣는 저장소입니다.

**폰에서 열기:** <https://tipitaka1.github.io/thai-srt-work/>
홈 화면에 추가하면 앱처럼 열립니다 (안드로이드 크롬: 메뉴 → 홈 화면에 추가 / 아이폰 사파리: 공유 → 홈 화면에 추가).

지금 들어 있는 법문: 루앙따 마하부와 「모든 괴로움 덩어리는 감각 욕망 번뇌에 모여 있다」(2003년 10월 11일 저녁, 왓빠반땃 스님들에게) 중 9:20~9:53 샘플.

## 화면

- 태국어 단어 위 작은 글씨가 한글 독음, 아래 줄이 한국어 번역입니다.
- 단어나 문장을 누르면 그 자리부터 재생합니다.
- 「보기」에서 글자 크기, 줄 간격, 독음·번역 보이기를 바꿉니다. 고른 값은 그 폰에 기억됩니다.
- 화면은 지금 문장이 아래쪽에 닿을 때만 한 번에 넘어갑니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` | 웹앱 |
| `talks.json` | 앱에 뜨는 법문 목록 |
| `media/` | 샘플 음성(mp3)과 자막(vtt) |
| `subtitles/` | 전체 노래방 VTT(1~180줄 독음·번역), 검토용 독음·번역 SRT |
| `work/LT2401/` | 휘스퍼 원본 SRT, 단어별 시각 JSON, 독음·번역(`pron_ko.txt`, 검토 표시 포함), 독음 토막에 맞춘 태국어 토막(`seg_th.txt`) |
| `tools/build_karaoke.py` | 위 자료로 VTT를 만드는 스크립트 |

## 법문 추가하기

1. `media/`에 mp3와 vtt를 넣습니다.
2. `talks.json`에 항목을 하나 더 적습니다 (`id`, `title`, `speaker`, `date`, `audience`, `audio`, `vtt`). 두 개 이상이면 맨 위에 고르는 칸이 생깁니다.

## VTT 형식

```
102
00:00:03.460 --> 00:00:09.180
<ruby>จะ<rt>짜</rt></ruby> <00:00:03.640><ruby>ไม่<rt>마이</rt></ruby> …
<c.ko>다른 길은 없다고요. …</c>
```

- `<ruby>태국어<rt>독음</rt></ruby>`: 단어와 독음 한 쌍
- `<시:분:초.밀리초>`: 다음 단어가 시작하는 시각 (단어 바로 뒤에 붙은 시각은 그 단어가 끝나는 시각)
- `<c.ko>…</c>`: 한국어 번역 줄

단어 시각은 휘스퍼 단어 시각을 글자 위치로 나눠 잡은 뒤, 단어 앞뒤에 0.12초 넘게 붙은 무음을 음성 크기로 잘라 낸 값입니다. 화면용 VTT에서는 번역의 검토 표시(※, (?), 휘스퍼 메모)를 뺍니다.

## 다시 만들기

```
python3 tools/build_karaoke.py \
  --srt  work/LT2401/LT2401_2003-10-11.srt \
  --json work/LT2401/LT2401_2003-10-11_words.json \
  --mp3  <원본 mp3 경로> \
  --data work/LT2401 \
  --out  subtitles/LT2401_2003-10-11_karaoke.vtt \
  --site .
```

ffmpeg와 numpy가 필요합니다. 원본 25분 mp3는 저장소에 넣지 않았습니다.
